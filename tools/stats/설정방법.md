# HotelEng 통계·설문 설정 (Google 스프레드시트 + Apps Script)

1. 기존 통계 스프레드시트를 복사합니다 (파일 > 사본 만들기). 이름 예: **HotelEng 통계**
   - 사본의 `events`, `survey` 시트에 남은 기존 기록은 지워 주세요 (1행 제목은 둬도 됩니다).
2. 사본에서 **확장 프로그램 > Apps Script** 를 엽니다.
3. `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs` 전체를 붙여 넣고 저장합니다.
4. 위쪽 함수 선택에서 **setup** 을 고르고 **실행** (처음 한 번 권한 허용).
5. **배포 > 새 배포 > 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
6. 배포 후 나오는 **웹 앱 URL (…/exec)** 을 Claude에게 보내 주세요. 앱의 STATS_URL에 넣습니다.

※ 사본을 만들면 기존 스크립트 배포는 따라오지 않으므로 반드시 **새 배포**로 새 URL을 만들어야 합니다.
※ 나중에 Code.gs를 고치면: 배포 > 배포 관리 > 연필 > 버전: 새 버전 > 배포 (URL은 그대로).
